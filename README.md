# Superstore Customer Intelligence & Profitability Analysis

## Project Overview
An end-to-end data analytics project exploring customer behavior, repeat purchases, sales performance, and profitability using the Superstore dataset.

## Objectives
- Analyze customer purchasing behavior.
- Measure repeat customer activity.
- Segment customers using RFM analysis.
- Identify high-value customers and profitability patterns.
- Track sales trends and compare customer segments.
- Develop actionable business recommendations.

## Tools & Technologies
- **Python:** data analysis and customer-level calculations
- **SQL:** data querying, KPI validation, and segmentation
- **Tableau:** interactive dashboard and visual storytelling
- **GitHub:** project documentation and version control

## Key KPIs
- Total customers
- Repeat customers and repeat purchase rate
- Top 10 customers' share of sales
- Average customer sales
- Total customer profit and profit margin

## Dashboard
The Tableau dashboard includes customer segmentation, sales and profit comparisons, top customers by profit, revenue trends, profitability distribution, and key insights.
